# AI-Based Resume Analyzer System

## 📌 Project Overview

The AI-Based Resume Analyzer System is a Java Swing-based desktop application that helps job seekers evaluate and improve their resumes through intelligent analysis. The system examines key resume sections such as skills, education, experience, keywords, and formatting to generate a comprehensive evaluation report.

By comparing resume content with industry-specific job requirements, the application provides role-based scoring, ATS (Applicant Tracking System) compatibility analysis, skill gap identification, strengths and weaknesses assessment, and personalized recommendations. The goal is to assist users in creating professional, job-ready resumes that increase their chances of securing interviews and career opportunities.


## 🚀 Key Features

- Role-Based Resume Scoring

## ▶️ How to Run

### Prerequisites

- Java 11 or higher installed

### Run Using JAR File

```bash
java -jar ResumeAnalyzer.jar
```

### Run Using Windows

```bash
run.bat
```

### Run Using Linux/Mac

```bash
chmod +x run.sh
./run.sh
```
